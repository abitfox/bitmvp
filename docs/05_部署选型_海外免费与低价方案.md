# 05 部署选型：海外免费与低价方案

> 场景：BitMVP 作品集（Next.js 15 App Router + API 路由 + wagmi 前端），域名 bitmvp.com，
> 访问量 = 求职作品集级别（月 PV 几百到几千），无长期驻留服务需求（暂未上 MySQL）。

## 一、结论先行

| 需求 | 推荐 |
|---|---|
| 作品集直接上线 | **Vercel Hobby（免费）**，5 分钟部署 |
| 要不限流量 / 允许商用 | Cloudflare Pages（免费） |
| 想要长驻服务器 + 自建 MySQL + 宝塔习惯 | RackNerd 年付 ~$11 或 Hetzner ~€4.5/月 |
| 白嫖高配 VPS | Oracle Cloud 免费层（4C/24G ARM，但注册像抽卡） |

## 二、免费托管平台对比（2026 年）

| 平台 | 带宽 | 构建 | 函数调用 | 免费用自定义域名 | 商用 | 特点 |
|---|---|---|---|---|---|---|
| **Vercel Hobby** | 100 GB/月 | 6000 分钟/月 | 100 万/月 | ✅ 免费 + 自动 HTTPS | ❌ 仅个人非商用 | Next.js 零配置，DX 天花板 |
| **Cloudflare Pages** | **无限** | 500 次/月 | 10 万/天 | ✅ | ✅ | 300+ 边缘节点，但 Next.js SSR 需 OpenNext 适配，较折腾 |
| Netlify | 100 GB/月 | 300 分钟/月 | 12.5 万/月 | ✅ | ✅ | 静态站强，Next.js 支持不如 Vercel |
| Render | 静态无限 | — | 有 | ✅ | ✅ | 免费动态服务 15 分钟不活动会休眠，冷启动 30s+ |
| Railway | 无真免费层（$5/月试用金） | — | — | ✅ | ✅ | 适合跑后端 + 数据库，不适合纯前端 |

### 为什么是 Vercel

1. **Next.js 官方平台**：App Router / RSC / API 路由全部零配置，不用任何适配层。
2. **部署最简单**：GitHub 连上后 `git push` 自动部署，每个 PR 自动生成预览 URL。
3. **限额对你的场景绰绰有余**：作品集月 PV ~2000 只消耗约 5 GB 带宽、4000 次函数调用，距离 100 GB / 100 万的限额差两个数量级。
4. **自定义域名免费**：bitmvp.com 直接绑，自动签 TLS。

### Vercel Hobby 的注意点

| 限制 | 对 BitMVP 的影响 |
|---|---|
| 禁止商业使用 | 求职作品集属于个人项目，✅ 合规；真要做产品再升 Pro（$20/月） |
| 函数超时 10 秒 | 你的链上 RPC 调用（Multicall/Quoter）通常 <2s，✅ 够用；CoinGecko 偶发慢时注意缓存 |
| 团队成员 1 人 | 单人项目无影响 |
| `*.vercel.app` 默认域名在国内基本被墙 | **必须绑自定义域名** bitmvp.com（见下文国内访问） |
| 日志只保留 1 小时 | 排障要趁热看 |

## 三、国内访问的关键点（绑自定义域名后）

- `bitmvp.com` 解析到 Vercel 的 anycast IP，国内**一般可直连**，但速度因地区/运营商而异（电信一般、移动较好）。
- 建议用 **DNSPod / 阿里云 DNS** 做 NS 或 CNAME 接入，而不是把域名 NS 转到 Cloudflare（避免被识别为代理流量）。
- Vercel 控制台（vercel.com）国内访问不稳定，部署建议走 **GitHub 自动集成**（本地推 GitHub 有代理即可），少依赖控制台。
- 面试官如果在国内打开慢：作品集首页做了静态导出/缓存的话体验会好很多（BitMVP 首页本来就是静态品牌页）。

## 四、低价 VPS（想自己掌控服务器时）

| 提供商 | 价格 | 配置 | 适合 |
|---|---|---|---|
| **RackNerd** | ~$11/年（闪购） | 1GB / 1C / 18GB | 最便宜的试水，续费同价 |
| **Hetzner** | ~€4.5/月 | 2GB / 2C / 20GB | 开发者口碑之王，性能/价格比最高 |
| Contabo | ~$6/月 | 4GB / 200GB | 内存大碗，但磁盘 IO 一般 |
| DigitalOcean / Vultr | $4-6/月 | 1GB | 文档最好，贵一点 |
| 搬瓦工 CN2 GIA | ~$50/年起 | 1GB | 国内直连质量最好，但常年缺货 |
| **Oracle Cloud 免费层** | 免费 | 最高 4C/24G ARM | 白嫖之王，但注册成功率低、随时可能回收，不建议放正式项目 |

**什么时候需要 VPS 而不是 Vercel：**
- 要自建 MySQL（配合宝塔，你已有运维习惯）
- 要跑长驻进程（如 Copilot 模块的 SSE/WebSocket 长连接、定时任务）
- 要部署非 Node 的东西

BitMVP 现阶段四个模块全是「前端 + 无状态 API 路由」，**没有必须 VPS 的理由**。

## 五、数据库补充（将来若需要）

- 作品集暂时不需要数据库，mock 数据 + 链上实时数据已够。
- 若 P5 Copilot 或用户系统要持久化：
  - **Neon**（Postgres 免费层 0.5GB）— Serverless 场景最顺
  - **Aiven**（MySQL 免费层）— 坚持用 MySQL 的话
  - 或直接上 VPS 自建 MySQL（宝塔一键装）

## 六、推荐路径

```
现在（P1-P4 收尾）     →  Vercel Hobby 免费部署 bitmvp.com
P5 Copilot（若需长驻）  →  评估 Railway $5 或 RackNerd 年付 VPS
真要做产品/商用         →  Vercel Pro 或迁移 Hetzner
```

## 七、部署 Checklist（Vercel 路线）

1. site/ 推到 GitHub 私有仓库（代码里有链配置，公开也无所谓，无敏感 Key）
2. vercel.com 用 GitHub 登录 → Import 项目 → 框架自动识别 Next.js
3. 环境变量：当前代码无必须项（RPC/代币清单硬编码在 lib/chain/）
4. 部署后先测 `https://xxx.vercel.app`（需代理），再在 Vercel 控制台绑 bitmvp.com
5. DNSPod 添加 CNAME：`www.bitmvp.com → cname.vercel-dns.com`，`@ 用 ALIAS/A 记录 → 76.76.21.21`
6. 验证：国内 4G 直连打开 bitmvp.com，测 /portfolio /swap /radar 三个页面
