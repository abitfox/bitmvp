## 二、配色选型

### 推荐：方案 A · Deep Vault 深穹

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 | `#0A0E1A` | 页面底色 |
| 表面 | `#151B2B` | 卡片、面板 |
| 边框 | `#2A3448` | 分隔线、描边 |
| **主色** | `#00D3B4` | 按钮、链接、强调 |
| 主色深 | `#0F6E56` | hover、次要强调 |
| **AI 专属** | `#7C5CFF` | Copilot 模块专用 |
| 主文字 | `#E8ECF4` | 标题、数值 |
| 次要文字 | `#8B94A7` | 说明、标签 |

**选型理由**
1. 深色是钱包/交易所的主流语言（MetaMask、Rainbow、Bitget Wallet 均如此）
2. 青绿主色潜意识呼应 Bitget，面试官会觉得「眼熟、顺眼」
3. 紫色专供 AI 模块 → 四个模块有主次，Copilot 天然显得「高一层」

### 备选方案（如不采用 A）

| 方案 | 主色 | 背景 | 适合场景 |
|---|---|---|---|
| B 信号白 | `#0F6E56` | `#F7F9FB` | 想做浅色、金融 SaaS 感、需要打印/截图 |
| C 链上暗金 | `#F5B544` | `#12100C` | 想强差异化、交易终端氛围 |

> 切换成本已降到最低：只需替换第十节的 CSS 变量值。

## 三、语义色（⚠️ 涨红跌绿）

**这是中国用户习惯，与欧美相反，务必遵守。**

| 语义 | 深色模式 | 浅色模式 | 用途 |
|---|---|---|---|
| **涨 / 上涨** | `#FF6B6B` 🔴 | `#E03131` | 正收益、买入、价格上升 |
| **跌 / 下跌** | `#3DD68C` 🟢 | `#12B76A` | 负收益、卖出、价格下降 |
| 成功 | `#3DD68C` | `#12B76A` | 交易成功 |
| 警告 | `#F5B544` | `#BA7517` | 滑点过高、Gas 异常 |
| 危险 | `#FF6B6B` | `#E03131` | 交易失败、风险提示 |
| 信息 | `#5B9DEF` | `#185FA5` | 提示、说明 |

> ⚠️ 常见错误：照抄国外模板做成「涨绿跌红」，中国面试官/用户会立刻觉得不对劲。
> 在 Portfolio 的涨跌幅、Radar 的资金流向上尤其明显。

## 四、四模块色彩归属

**原则**：主色统一，模块色仅用于**小面积标识**（图标、badge、模块页顶部装饰），避免整站花掉。

| 模块 | 标识色 | 应用位置 |
|---|---|---|
| **Portfolio** | `#00D3B4` 青绿 | 模块图标、资产条 |
| **Swap** | `#5B9DEF` 蓝 | 交易按钮、状态指示 |
| **Radar** | `#A78BFA` 浅紫 | 图表、资金流向 |
| **Copilot** | `#7C5CFF` 紫 | **专属色**，AI 标识、对话气泡 |

> Copilot 用紫色的意义：视觉上把它从「三个功能模块」里提出来，强化「它是统一入口、是更高一层」的架构关系。

## 五、字体

```css
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Microsoft YaHei", sans-serif;
--font-mono: "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;
```

| 场景 | 字体 | 字号 |
|---|---|---|
| 页面标题 H1 | sans | 32–40px |
| 模块标题 H2 | sans | 24px |
| 卡片标题 H3 | sans | 16px |
| 正文 | sans | 14–15px |
| **地址 / 哈希 / 数值** | **mono** | 13–14px |

> ⚠️ **钱包产品细节**：所有地址、交易哈希、代币数量**必须用等宽字体**。
> 这是专业钱包的基本素养，也是面试时会被注意到的细节。

## 六、间距与圆角

| Token | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 紧凑间隙 |
| `--space-2` | 8px | 元素内间距 |
| `--space-3` | 12px | 卡片内边距（小） |
| `--space-4` | 16px | 卡片内边距 |
| `--space-6` | 24px | 模块间距 |
| `--space-8` | 32px | 区块间距 |

| 圆角 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 按钮、badge |
| `--radius-md` | 10px | 卡片 |
| `--radius-lg` | 16px | 大面板、弹窗 |
| `--radius-full` | 999px | 头像、pill 标签 |

## 七、组件规范

### 按钮
| 类型 | 填充 | 文字 | 边框 |
|---|---|---|---|
| 主按钮 | `#00D3B4` | `#0A0E1A` | 无 |
| 次按钮 | 透明 | `#E8ECF4` | `#2A3448` |
| 危险 | `#FF6B6B` | `#0A0E1A` | 无 |
| 禁用 | `#1E2536` | `#5A6376` | 无 |

- 高度：40px（桌面）/ 44px（移动端，触控友好）
- 圆角：`--radius-sm`

### 卡片
- 背景 `#151B2B`，边框 `#2A3448`（0.5px），圆角 10px
- 内边距 16px
- **不加阴影**（扁平化，深色下阴影无意义）

### 表格（Portfolio / Radar 大量使用）
- 表头：`#0F1522` 底，文字 `#8B94A7`，12px
- 行高 48px，隔行 `#121826`
- 数值列**右对齐 + 等宽字体**

### 交易状态 Badge（Swap 核心）
| 状态 | 颜色 | 文案 |
|---|---|---|
| 待签名 | `#8B94A7` | 等待签名 |
| 打包中 | `#F5B544` | 确认中 |
| 成功 | `#3DD68C` | 已完成 |
| 失败 | `#FF6B6B` | 失败 |

### Toast
- 位置：右上（桌面）/ 顶部（移动端）
- 成功绿边、失败红边、警告黄边

## 八、Logo 规范（概念一 · Node Block）

**推荐理由**：方块＝区块，四节点互联＝网络；纯几何、缩放不失真、favicon 友好、可手写 SVG。

### SVG 源码（可直接用）

```svg
<svg viewBox="0 0 32 32" xmlns="http://www.w3.org/2000/svg">
  <rect width="32" height="32" rx="8" fill="#0A0E1A"/>
  <g stroke="#0F6E56" stroke-width="1.5">
    <line x1="10" y1="10" x2="22" y2="22"/>
    <line x1="22" y1="10" x2="10" y2="22"/>
    <line x1="10" y1="10" x2="22" y2="10"/>
    <line x1="10" y1="22" x2="22" y2="22"/>
  </g>
  <circle cx="10" cy="10" r="3.5" fill="#00D3B4"/>
  <circle cx="22" cy="10" r="3.5" fill="#00D3B4"/>
  <circle cx="10" cy="22" r="3.5" fill="#0F6E56"/>
  <circle cx="22" cy="22" r="3.5" fill="#0F6E56"/>
</svg>
```

### 使用规则
| 项 | 规范 |
|---|---|
| 最小尺寸 | 24px（小于此用纯色简化版） |
| 安全边距 | Logo 高度的 1/4 |
| 深色底 | 用上方版本（底色 `#0A0E1A`） |
| 浅色底 | 底色改 `#FFFFFF`，节点色不变 |
| 禁止 | 拉伸变形、改色、加阴影、旋转 |

### 字标组合
`[Logo] BitMVP` — 水平排列，间距 8px，字标用 500 字重。
子模块写作 `BitMVP Portfolio`，模块名用次要文字色。

## 九、落地代码

### CSS 变量（方案 A，直接复制）

```css
:root {
  /* 背景与表面 */
  --bg:            #0A0E1A;
  --surface:       #151B2B;
  --surface-alt:   #0F1522;
  --border:        #2A3448;

  /* 主色 */
  --primary:       #00D3B4;
  --primary-dark:  #0F6E56;
  --ai:            #7C5CFF;

  /* 文字 */
  --text:          #E8ECF4;
  --text-muted:    #8B94A7;

  /* 语义 */
  --up:            #FF6B6B;   /* 涨 · 红 */
  --down:          #3DD68C;   /* 跌 · 绿 */
  --success:       #3DD68C;
  --warning:       #F5B544;
  --danger:        #FF6B6B;
  --info:          #5B9DEF;

  /* 模块 */
  --m-portfolio:   #00D3B4;
  --m-swap:        #5B9DEF;
  --m-radar:       #A78BFA;
  --m-copilot:     #7C5CFF;

  /* 字体 */
  --font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI",
               "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono: "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;

  /* 圆角 */
  --radius-sm: 6px;
  --radius-md: 10px;
  --radius-lg: 16px;
}
```

### Tailwind 配置（tailwind.config.ts）

```ts
import type { Config } from "tailwindcss";

export default {
  content: ["./app/**/*.{ts,tsx}", "./components/**/*.{ts,tsx}"],
  theme: {
    extend: {
      colors: {
        bg: "var(--bg)",
        surface: { DEFAULT: "var(--surface)", alt: "var(--surface-alt)" },
        border: "var(--border)",
        primary: { DEFAULT: "var(--primary)", dark: "var(--primary-dark)" },
        ai: "var(--ai)",
        up: "var(--up)",
        down: "var(--down)",
        portfolio: "var(--m-portfolio)",
        swap: "var(--m-swap)",
        radar: "var(--m-radar)",
        copilot: "var(--m-copilot)",
      },
      fontFamily: {
        sans: ["var(--font-sans)"],
        mono: ["var(--font-mono)"],
      },
      borderRadius: {
        sm: "var(--radius-sm)",
        md: "var(--radius-md)",
        lg: "var(--radius-lg)",
      },
    },
  },
  plugins: [],
} satisfies Config;
```

> 用法示例：`<div className="bg-surface border border-border rounded-md">`、涨用 `text-up`、跌用 `text-down`。

## 十、明暗模式（可选，建议先只做深色）

若后续加浅色模式，用 `[data-theme="light"]` 覆盖变量即可：

```css
[data-theme="light"] {
  --bg: #F7F9FB;  --surface: #FFFFFF;  --border: #E6EAF0;
  --text: #1A2233; --text-muted: #5B6474;
  --up: #E03131;  --down: #12B76A;
}
```

> 建议：**先只做深色**，把功能做完再考虑。多一套主题等于多一倍维护成本，对求职作品集性价比低。
