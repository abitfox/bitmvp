# 需求 12《别人在买什么：扫区块》策划案 · 思考流口播版

目标时长 7 分钟。视角铁律见 `lab/00-内容标准.md`。上集钩子：别人的交易在区块里。本集全程终端。

## 思考主线（先看骨架）

```
T1 换个方向：从管自己的钱到看别人的 → T2 不想经过二道贩子 → T3 一个区块里有什么
→ T4 捞大额转账 → T5 实测：鲸鱼今天安静 → T6 新问题：总不能一直盯着终端
```

## T1 · 换个方向（0:00–0:40）

〔屏幕：Portfolio 页面自己地址的余额〕

> 写链打通后，我盯着自己的资产总有点孤独：只有我知道我在干嘛。真正的市场信号在别人那里——大鲸鱼现在在搬什么？
>
> 但我又不想用现成的行情 App：那些数据不知道被几家转手加工过。今天我换个路子：自己直接去看链上的原始交易。

## T2 · 不想经过二道贩子（0:40–1:30）

〔屏幕：笔记卡「信号取自原始区块，不经过转述」〕

> 市面工具的「鲸鱼监控」，数据链路大多是：链 → 数据商清洗 → 再转卖给工具 → 再转述给我。每过一手，都会丢点东西、加点解读。
>
> 我的路子笨一点但干净：**直接扫最新区块的原始交易**。反正 01 集就说过，节点手里有全部状态——区块就是这本账最新的一页，公开可翻。

## T3 · 一个区块里有什么（1:30–2:40）

〔屏幕：`lab/labs/12-block-scan.ts` 前半段，现场敲〕

```ts
const block = await client.getBlock({ blockTag: "latest" });
console.log("块高:", block.number);
console.log("交易数:", block.transactions.length);
console.log("Base Fee:", formatGwei(block.baseFeePerGas), "gwei");
```

> `getBlock` 一次拿回一整块：块高、时间戳、Gas、还有全部交易列表。以太坊大约 12 秒出一个块——意思是这本账每 12 秒翻一页，我每 12 秒就能看一次「刚刚全世界发生了什么」。

## T4 · 捞大额转账（2:40–3:40）

> 交易列表里大部分是噪音。我定的「鲸鱼」标准很简单：**转账价值 ≥ 50 ETH** 的原生币转账。遍历交易的 `value` 字段过滤：

```ts
const whales = block.transactions.filter((tx) => tx.value >= 50e18);
```

> 50 ETH 这个阈值是我拍的，今天先跑起来再调。装饰一下输出：时间、从哪、到哪、金额。

## T5 · 实测：鲸鱼今天安静（3:40–5:40）

〔终端：循环每 12 秒扫一个新块，连扫几分钟〕

> 跑起来——第一个块 125 笔交易，大额转账：0 笔。（停顿）零笔？白扫了？（停顿）不，我盯着这个 0 看了会儿，反而品出点东西：**没有大额转账本身就是信息**——鲸鱼安静的时候，市场大概率也在等。这跟价格数据不一样：价格永远有个数，而「没发生什么」只能从原始区块里看出来。这波不亏。
>
> 扫了几分钟后逮到一笔 62 ETH 的转账，从·到·金额打出来，时间戳精确到秒。这就是账本原文，没有经过任何人转述。

## T6 · 新问题：总不能一直盯着终端（5:40–6:10）

> 能捞到信号了，但方式太苦力：终端循环、人肉盯屏。这种东西就该挂在页面上自己刷新。
>
> 下一集：把扫区块搬上网页——第二个页面。好消息是套路 07 集已经练过一遍了。

## 实测清单

- 单块解析输出（块高/交易数/Gas）
- 连续扫块几分钟（大概率有 0 笔的块，也有真实鲸鱼转账；提前彩排确认当天主网「活着」）
- 阈值 50 ETH 的过滤前后对比（可选：先打印全部交易量级再过滤，对比冲击感）
