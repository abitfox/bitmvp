# 需求 08《我想换币：先问链能换多少》策划案 · 思考流口播版

目标时长 7 分钟。视角铁律见 `lab/00-内容标准.md`。上集钩子：看到 USDT 想换 ETH，凭什么要去 Uniswap 官网。

## 思考主线（先看骨架）

```
T1 换币的第一步不是换，是问价 → T2 本来想接聚合 API，查完价格劝退
→ T3 报价的本质是读合约：QuoterV2 → T4 100 USDC 能换多少 WETH
→ T5 对账实验 → T6 新问题：跟网页对不上
```

## T1 · 换币的第一步不是换，是问价（0:00–0:40）

〔屏幕：Uniswap 官网换币页〕

> 换币这个需求听起来吓人——要把真金白银发出去。我把它拆小：**成交之前，一切都可以只读**。第一步根本不是换，是问：100 USDC 能换多少 WETH？今天就只做这一步，终端里问，不碰钱包。

## T2 · 本来想接聚合 API，查完价格劝退（0:40–1:50）

〔屏幕：笔记卡「0x / 1inch：2026 年起按次收费」〕

> 最省事的路线是接 0x 或 1inch 这类聚合 API——它们把各家报价汇总好喂给你。我本来都准备去申请 key 了，查了下现状：这两家从 2026 年开始都改成按请求收费了。
>
> 免费路线还有没有？查到了：直接读链上的 Uniswap V3 Quoter 合约。它是个只读合约，传入「你有什么、要什么、多少」，它告诉你按当前池子状态能换多少。免费，代价是只有 Uniswap 一家的报价——对学习目的正合适。

## T3 · 报价的本质是读合约（1:50–3:20）

〔屏幕：笔记卡「报价 = 一次合约读操作，不是魔法」〕

> 说的玄乎，本质上还是 02 集那套 `readContract`：合约地址 + ABI + 函数名 + 参数。
>
> 但这里我结结实实踩了个坑，值得讲：我拿着网上抄来的 QuoterV2 地址和「元组签名」去调——被空 revert 拒了。查 Uniswap 官方部署表才发现：**以太坊主网根本没部署 QuoterV2，只有 V1**（V2 在 Base 这些后发的链上）。更坑的是 V1 签名还不一样：flat 参数、且 **fee 在 amountIn 前面**。我按 V2 的参数顺序传，被无声拒绝，连报错原因都不给。
>
> 〔终端：错误签名 → 空 revert；正确签名 → 出数（前后对照镜头）〕
>
> 02 集的功力今天全部复用——写换币居然还是「读」；读的学费，是签名里一个参数的顺序。

## T4 · 100 USDC 能换多少 WETH（3:20–4:20）

〔屏幕：`lab/labs/08-quote.ts`，现场敲〕

```ts
const amountOut = await client.readContract({
  address: QUOTER_V1, abi: QUOTER_ABI,   // 主网只有 V1
  functionName: "quoteExactInputSingle",
  args: [USDC, WETH, 500, parseUnits("100", 6), 0n],
  //                    ↑ fee 在 amountIn 前面（V1 与 V2 的差异）
});
```

> 跑一下，终端吐出一个数：0.0429 ETH 左右。（停顿）这一刻有点奇妙——没连钱包、没花钱、没签名，但我已经「完成」了换币最核心的信息获取：知道这笔交易值多少。

## T5 · 对账实验（4:20–5:40）

> 数字不能自嗨，我去 Uniswap 官网输入同样的一笔，对一下数。（停顿）差了一点点——不是 bug：网页从打开到查询有时间差，池子每一秒都在变。方向和大致比例对得上，就说明我读对了合约。
>
> 顺手验证了另一件事：改 `amountIn` 为 10000 USDC，报价的兑换率变差了——大单砸进池子会打穿价格曲线，这个「价格影响」的概念今天先眼见为实。

## T6 · 新问题：跟网页对不上，还有别的池子（5:20–6:00）

> 对账时我还发现一个更值得挖的线索：同一个交易对，Uniswap 界面上能选「0.05% / 0.3%」不同的费率——意思是一对代币之间居然有**好几个池子**，价格各不相同。那哪家的价最好？
>
> 下一集：把几个池子都问一遍，挑最划算的。

## 实测清单

- 100 USDC → WETH 报价（主网真实数据，实测输出约 0.0429 WETH）
- 与 Uniswap 官网同参数对账（允许小差异，录屏时两边同屏）
- 100 与 10000 USDC 两档报价对比（价格影响实验）
- 错误签名（V2 元组版）vs 正确签名（V1 扁平版）的前后对照镜头
