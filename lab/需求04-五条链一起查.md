# 需求 04《我在五条链上都有资产》策划案 · 思考流口播版

目标时长 7 分钟。视角铁律见 `lab/00-内容标准.md`。上集钩子：五条链的资产，难道复制五份代码？

## 思考主线（先看骨架）

```
T1 一条链不通天下 → T2 链是什么：另一本账+另一组节点 → T3 先写出惨状再重构
→ T4 配置化：chains 表 → T5 串行太慢，并行 → T6 五链余额表 → T7 意外与钩子
```

## T1 · 一条链不通天下（0:00–0:30）

〔屏幕：钱包里的多链资产截图〕

> 前三集把以太坊一条链读通了。但打开我的钱包，资产散在五条链上：Ethereum、Base、Arbitrum、Optimism、BNB Chain。今天的问题：一次性查全，而且我不想复制五份代码。

## T2 · 链是什么：另一本账 + 另一组节点（0:30–1:20）

〔屏幕：笔记卡「一条链 = 一本独立账本 + 一组节点」〕

> 先把「链」想明白。Base、Arbitrum 这些 Layer2，本质上都是**独立的账本**：有自己的节点群、自己的状态。查它们的余额，就是问它们自己的节点——跟以太坊的问法一模一样，只是入口地址不同。
>
> 所以五条链的差异，其实只有三个数据：链的标识、节点入口（RPC）、还有各链上代币合约地址不同。差异这么小，凭什么复制五份代码？

## T3 · 先写出惨状再重构（1:20–2:20）

〔屏幕：现场写一段 if/else 复制粘贴版，故意写丑〕

> 我先把「能跑」的版本写出来：以太坊一段、Base 一段，复制粘贴改改。写到第三段我自己受不了了——每段只差三个常量，剩下全是复制。
>
> 惨状是最好的重构理由：差异既然只有三个常量，那就把差异抽成**数据**，逻辑只写一份。

## T4 · 配置化：chains 表（2:20–3:20）

〔屏幕：`lab/labs/04-multichain.ts`，chains 定义〕

```ts
const CHAINS = [
  { name: "Ethereum", chain: mainnet,   tokens: [USDT, USDC, WETH] },
  { name: "Base",     chain: base,      tokens: [USDC, WETH, AERO] },
  { name: "Arbitrum", chain: arbitrum,  tokens: [USDT, USDC, ARB] },
  // ...
];
```

> 这就是 BitMVP 成品里 `lib/chain/chains.ts` 的雏形：链是配置，不是代码。以后加一条链，就是往表里加一行——这个体验以后会反复验证。

## T5 · 串行太慢，并行（3:20–4:20）

> 遍历五条链，我顺手写了个 for 循环 await——跑了一下五秒多。等等，每条链是独立的账本、独立的节点，问 B 链不用等 A 链回答。串行完全没道理。
>
> 改成 `Promise.all` 五个请求同时发。（停顿）五秒变一秒。跟 02 集 Multicall3 是同一个思想，只是层次不同：Multicall 是链内打包，这里是链间并行。

## T6 · 五链余额表（4:20–5:00）

〔终端：跑 `lab/labs/04-multichain.ts`〕

> 输出一张五链余额表，每条链一节，格式化的余额。到这一步，02 集的所有积木（multicall、decimals、client）在新链上原样能用——配置化的好处第一次显形。

## T7 · 意外与钩子（5:00–5:40）

> 最后我干了个破坏性实验：把 Base 的 RPC 换成一个假地址——（停顿）整张表全崩了。`Promise.all` 一个失败全体失败，Base 挂了居然 Ethereum 也显示不出来。
>
> 这个坑今天记下不修——一条链挂了只降级那一条，是个正经话题，留给插集。今天的钩子在别处：余额全部到齐，但它们值多少钱？USDT 写着 1222，可它值 1222 美元吗？下一集接价格。
